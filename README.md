# Homebrew Tap for RikaiDev

This repository contains Homebrew formulae for RikaiDev tools.

## Installation

```bash
brew tap RikaiDev/tap
brew install toki
```

Or install directly:

```bash
brew install RikaiDev/tap/toki
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| [innen](Formula/innen.rb) | Deterministic, zero-daemon CLI knowledge engine for LLM agents (Karpathy LLM Wiki) |
| [toki](Formula/toki.rb) | Automatic time tracking for developers |
